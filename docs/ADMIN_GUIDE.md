# WasteLoop — Operations & Administrative Guide

## Executive Overview
The **WasteLoop Administrative Suite** provides municipal authorities, site supervisors, recycling partners, and enterprise organization managers with operational command center tools for real-time waste tracking, fleet routing, AI anomaly detection, and material circularity management.

---

## Roles & Access Matrix

| Role | Target Portal | Key Capabilities |
| :--- | :--- | :--- |
| **Supervisor** | `/supervisor` | Fleet dispatch, collector route verification, bin overflow override, task reassignment. |
| **Municipal Admin** | `/admin` | City-wide heatmaps, route optimization algorithms, zonal SLA monitoring, ML forecasting. |
| **Recycler** | `/recycler` | Batch processing intake, purity grading (A/B/C/D), marketplace listings, certificate issuance. |
| **Org Admin** | `/org-admin` | Institutional bulk scheduling (University/Restaurant/Office), ESG audit logs, carbon reporting. |
| **Platform Admin** | `/system-admin` | System health diagnostics, Supabase RLS policy management, ML microservice model sync. |

## 1. Supervisor Dashboard Operations (`/supervisor`)

### 1.1 Managing Field Collectors & Assignments
- **Live Fleet Tracking**: Real-time status cards display collector GPS ping time, battery status, vehicle payload capacity, and assigned route completion percentage.
- **Task Reassignment Modal**: Click **Reassign Collector** on any open collection request to delegate tasks based on geographical proximity and collector workload.
- **Manual SLA Override**: Approve delayed pickups or reclassify misreported waste types (e.g. converting falsely tagged organic waste to hazardous/special handling).

### 1.2 Incident & Issue Resolution
- Review evidence photos submitted by citizens via `wl_incidents`.
- Inspect location coordinates, issue urgency level (Low/Medium/High/Critical), and trigger rapid dispatch to the nearest available maintenance unit.

## 2. Municipal Admin Portal (`/admin`)

### 2.1 City-Wide GIS Analytics & Dynamic Route Optimization
- **Interactive Ward Map**: Multi-layer Leaflet visualization rendering bin fill levels, vehicle locations, and active collection routes.
- **Dynamic Routing Engine**: One-click route optimization recalculates pathing for waste trucks to minimize fuel consumption while prioritizing high-risk/overflowing bins (>85% fill level).

### 2.2 Coarse Sorting Tracker & Logistics Routing
- Track incoming collection batches at Central Transfer Stations.
- Select sorting logs to view **Log Separation & Recycler Routing Recommendations**.
- Route batches directly to verified recycling partners according to purity score and material classification (PET, HDPE, Aluminum, Cardboard, E-Waste).

### 2.3 ML Analytics & Waste Volume Forecasting
- Access 15 Recharts graphics detailing zonal generation trends.
- Analyze explicit data tags labeled with standard operational flags:
  - **FACT**: Historic weighbridge measurements and verified receipt totals.
  - **PREDICTION**: XGBoost seasonal volume forecasts generated by the Python ML microservice.
  - **RECOMMENDATION**: Automated resource allocation suggestions for truck crew dispatch.

## 3. Recycler Portal (`/recycler`)

### 3.1 Material Intake & Verification
- Scan or input batch codes (e.g., `WL-REC-2026-8841`) to pull origin information and collection metadata.
- Perform visual/sensor inspection and log **Purity Grade**:
  - **Grade A (95-100% pure)**: Highest value marketplace credit.
  - **Grade B (85-94% pure)**: Standard processing rate.
  - **Grade C (70-84% pure)**: Requires pre-wash & coarse manual sorting.
  - **Grade D (<70% pure)**: High contamination hazard, route to energetic recovery/RDF.

### 3.2 Certificate Issuance & QR Generation
- Generate tamper-evident **Circular Economy Certificates** with unique hash codes.
- Export formatted PDF Certificates featuring local SVG QR verification codes for instant audit lookup.

---

## 4. Organization Admin Portal (`/org-admin`)

### 4.1 Multi-Facility Profile Setup
- Toggle institutional modes: **University Campus**, **Restaurant/Hospitality Chain**, **Corporate Office Complex**.
- Configure custom pickup windows (e.g., night shifts for restaurants, early morning for academic centers).

### 4.2 ESG & Sustainability Reporting
- Export CSV/PDF reports detailing diverted waste tonnage, avoided CO₂ emissions, and circular economy compliance scores.
